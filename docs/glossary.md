# Glossary

## ALE

**Alcatel-Lucent Enterprise** - The laboratory environment for which this ticket management tool is being built.

## Ticket

A support request or task that needs to be tracked and resolved. Tickets contain information about issues, requested features, or work items.

## Backend

The server-side Python Flask application that handles API requests, business logic, and data processing.

## Frontend

The client-side React application that users interact with in their web browser.

## API

**Application Programming Interface** - The contract between frontend and backend defined by REST endpoints and JSON responses.

## REST

**Representational State Transfer** - Architectural pattern using HTTP methods (GET, POST, PUT, DELETE) for API design.

## JSON

**JavaScript Object Notation** - Lightweight data format used for API communication between frontend and backend.

## Blueprint

Flask concept for organizing routes and functionality into modular components.

## Route

An endpoint in the Flask backend that responds to HTTP requests.

## Schema

Database structure definition containing tables, columns, and relationships.

## Seed Data

Sample data used to populate the database for testing purposes.

## Vite

**Rapid build tool** - Frontend build tool and development server used with React.

## npm

**Node Package Manager** - Tool for managing JavaScript dependencies and running scripts.

## pip

**Package Installer for Python** - Tool for managing Python dependencies.

## Virtual Environment

Isolated Python environment with its own dependencies (venv).

## CORS

**Cross-Origin Resource Sharing** - HTTP mechanism allowing frontend and backend on different origins to communicate (not yet enabled).

## Authentication

Process of verifying user identity (required Phase 1 feature, planned for the Authentication milestone).

## CRUD

**Create, Read, Update, Delete** - Basic database operations.
